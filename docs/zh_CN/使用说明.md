# 使用说明

以下命令是固件日常使用的主要运维入口。

## 启动或重新部署

```bash
bash ./scripts/deploy.sh
bash ./scripts/deploy.sh --build
```

- `deploy.sh`
  默认拉取 `flight-core` 预编译镜像，构建默认 gateway 镜像并启动
- `deploy.sh --build`
  使用当前源码本地构建后再启动

默认 Nano 启动服务为：

- `flight-core`
- `control-gateway`
- `pointcloud-gateway`

可选能力通过 Compose profile 启用：

```bash
docker compose --profile media up -d media-gateway
docker compose --profile vision up -d vision-gateway
docker compose -f docker-compose.yml -f docker-compose.build.yml --profile planner up -d planner
```

## 仅重新构建

```bash
bash ./scripts/build.sh
```

`build.sh` 会基于当前仓库源码重新构建固件镜像，对应 `docker-compose.build.yml` 模式。
当前版本已对 fresh build 做过实机验证，并对基础依赖安装增加了自动重试。

## 启动或停止容器

```bash
bash ./scripts/up.sh
bash ./scripts/up.sh --build
bash ./scripts/down.sh
```

## 查看状态

```bash
bash ./scripts/status.sh
bash ./scripts/logs.sh
bash ./scripts/enter.sh
```

`enter.sh` 会进入运行容器内部，日常主要用于查看 `flight-core` 中的 ROS 状态。
容器内默认运行用户为 `uav`，便于日常运维时避免使用 root。
