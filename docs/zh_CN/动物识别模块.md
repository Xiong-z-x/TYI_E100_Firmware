# 2025 H 题动物识别模块

## 目标

该模块面向 2025 年全国大学生电子设计竞赛 H 题“野生动物巡查系统”，识别：

1. elephant
2. tiger
3. wolf
4. monkey
5. peacock

赛题使用打印后粘贴在地貌图上的动物体态图，而不是自然场景照片。普通 COCO
权重没有完整覆盖这五个类别。本模块使用 MegaDetector v5a 定位每一个动物框，
再用 Google SpeciesNet v4.0.3a 对每个框分类，并将其 2498 个自然分类标签的
概率质量聚合到五类闭集。

## 数据链路

```text
/dev/video0
  └─ orin-camera-stream.service（唯一设备所有者）
       ├─ 8090/snapshot.jpg
       └─ 8090/stream.mjpg
            └─ vision-gateway（只读 HTTP 快照，不挂载 /dev）
                 ├─ MegaDetector v5a / TensorRT FP16
                 ├─ SpeciesNet v4.0.3a / TensorRT FP16
                 ├─ 五类概率聚合、拒识和短时跟踪去重
                 ├─ 8765/healthz
                 ├─ 8765/v1/detections/latest
                 ├─ 8765/v1/events
                 ├─ 8765/v1/counts
                 ├─ 8765/snapshot.jpg
                 └─ 8765/stream.mjpg
```

`vision-gateway` 不读写 MAVROS、FAST-LIO、飞控串口或电机控制接口。视觉服务失败不会直接改变飞行状态。

## 模型与性能配置

默认配置：

```text
detector:         MegaDetector v5a
classifier:       SpeciesNet v4.0.3a always-crop
TensorRT:         两个 FP16 静态 batch=1 引擎
detector input:   1280x1280 NCHW
classifier input: 480x480 NHWC
target rate:      2 FPS
camera source:    1280x720 最新 JPEG 快照
detector gate:    0.20
closed-set gate:  0.60
native mass gate: 0.20
class margin:     0.15
box filter:       宽/高不超过画面 70%，面积不超过画面 25%
border filter:    距离画面四边至少 0.5%，被裁切目标进入画面后再确认
tracking confirm: 连续 3 帧
tracking expiry:  丢失 5 帧
```

MegaDetector 只负责 animal/person/vehicle 定位，不负责物种分类。SpeciesNet 原始
输出按分类学聚合：象使用 Proboscidea，虎使用 Panthera，狼使用 Canidae，猴使用
非人灵长类家族，孔雀使用 Phasianidae/Pavo。只有闭集条件概率、原生概率质量和
第一/第二名差值同时过门槛才进入候选轨迹；连续 3 帧后才确认并计数。否则输出
unknown，不把场景强行归为动物。

  `1.0`，最低动物框置信度 `0.8884`。
- 分类概率按五类分类学聚合后，15/15 类别正确且全部通过 0.8 门槛；狼、猴、

- v2 合成独立测试集 600 张，预训练闭集准确率 `59.0%`；unknown 拒识

## 计数边界

`/v1/counts` 中的 `sessionConfirmedTrackEvents` 只做时间维度的短时去重。无人机飞离后再次经过同一只动物，可能产生新的 track event。

赛题最终要求按网格统计。可靠的最终计数必须由任务层或地面站把检测中心、相机标定、无人机位姿和网格坐标融合后完成；不能把临时 track 数直接当作最终赛题答案。

合成集用于验证旋转、透视、缩放、模糊、压缩和地貌变化。因为验证与测试仍来自
同一张官方素材的不同姿态和地貌区域，它不能代替“打印动物图、按比赛高度和现场
光照实拍”的最终验证集。

## 预训练模型基线（2026-07-25）

测试输入为赛题官方 `动物体态.jpg`（15 个目标，象、虎、狼、猴、孔雀各
3 个），并进一步构造泄漏隔离的 v2 合成数据集用于后续 AutoDL 微调。

### YOLO11s-seg（COCO）

- 权重：Ultralytics 官方 `yolo11s-seg.pt`，20,669,228 bytes。
- SHA-256：
  `1CAA81C0195412EFA411B632BCFB8C184939DDDB6AE41F6A80C41B211FF257C3`。
- 15 个官方目标裁剪中，10 个存在置信度不低于 0.8 的检测，但只有 3 个检测
  的类别名与赛题目标完全一致，均为 `elephant`。
- 3 只虎均被高置信度识别为 `zebra`；狼主要识别为 `dog`；猴主要识别为
  `bear`/`dog`；孔雀只能识别为通用 `bird`。

结论：COCO 预训练模型的定位和视觉特征可复用，但其标签空间不含完整五类，
不能直接作为赛题最终分类器。它适合作为未来闭集微调的轻量分割骨干。

### Google SpeciesNet v4.0.3a + MegaDetector v5a

- SpeciesNet 分类器权重：224,393,837 bytes。
- MegaDetector 权重：280,767,041 bytes，SHA-256：
  `FE3E90E4B1955821AB7C1F88B446DC0C8CB25E109FDD1872916A55305294A5EF`。
- 官方整图检测 15 个框，和 15 个标注框在 IoU 0.5 下全部一一匹配：
  precision `1.0`、recall `1.0`、平均 IoU `0.7739`；最低检测置信度
  `0.8884`。
- 裁剪分类结果：象 3/3 为 `african elephant`（0.9957--0.9984）；虎
  3/3 为 `tiger`（0.9996--0.9998）；狼输出 `canis species` 或
  `grey wolf`（0.7775--0.8982）；猴仅稳定到 `animal`；孔雀稳定到
  `phasianidae family` 或 `pavo species`（0.6512--0.8727）。

结论：SpeciesNet/MegaDetector 是当前公开预训练模型中的主链路。原生标签的
单标签分数会分散到科、属、种；将完整概率向量按赛题五类分类学归并后，官方 15
个目标全部正确通过门槛。Nano 改用双 TensorRT 引擎，每个 MegaDetector 动物框
都独立分类，不采用官方脚本只分类最高置信度单框的限制。

## AutoDL 微调边界

最终数据集为 2760 张 480x480 MegaDetector 紧裁剪空间图像：

- train：1800（每类 300）
- val：360（每类 60）
- test：600（每类 100，绝不参与训练）
- 第六类 `unknown`：地貌负样本，用于学习拒识

train 使用官方姿态 0/1 和地貌左侧区域；val/test 使用保留姿态 2，val/test
分别使用地貌右上/右下区域。`autodl/train-val.csv` 的 location 分组已经用官方
SpeciesNet 微调器验证为 1800/360 的严格分割。

训练采用两阶段：先只训练分类头 12 epoch，再加载 Stage 1 最佳骨干、解冻最后
2 个阶段训练 24 epoch。合成集只用于域适配起点；部署最终权重前必须补入 Nano
实拍的真阳性和 MegaDetector 假阳性框，并在独立现场测试集上重新标定 0.8 门槛。

## 官方赛题域 YOLO11s-seg 模型（2026-07-26）

最终模型针对 2025 H 题五类闭集重新训练，不再把域不匹配的开放数据召回率作为
比赛验收指标。独立 test 为 1200 张图、1953 个目标，其中 551 张为多实例场景、
488 张为空场景。

推荐单帧候选阈值为 `0.70`：召回 `99.03%`、精确率 `99.59%`、多实例整场全命中
`97.28%`、空场景误报率 `0.205%`。最终权重为：

```text
C:\nano\state\vision-training\yolo11s-seg-nuedc-h-official-v2-20260726\best-hardneg.pt
size:    20,532,132 bytes
SHA-256: 8D7B5974BB2003926BA3CADC62BF05FDDF259C8E11D50A688B81A6A5B90D81F5
```

最终计数和数据上报不能只依赖单帧置信度。运行时采用非阻塞滑动窗口：

- `conf >= 0.85` 且尺寸/轮廓合理：最近 3 帧命中 2 帧即可确认；
- `0.70 <= conf < 0.85`：最近 5 帧命中 3 帧确认；
- 候选框立即显示，确认门槛只约束最终计数和上报；
- 已确认目标持续跟踪，不为每一帧重复等待确认。

10 FPS 时，2/3 与 3/5 从首次命中到最早确认约为 0.1 秒和 0.2 秒。服务器测试速度
不能代表 Jetson Nano；部署 TensorRT 后必须在 Nano 上分别测推理 FPS、端到端延迟和
CPU/GPU/内存占用。真实打印动物、110/120/130 cm 高度和飞行运动模糊测试通过前，
不得把合成测试结果表述为现场可用结论。
